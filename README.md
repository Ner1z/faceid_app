# NEON FaceID

Приложение контроля входа по лицу. Реализовано на PyQt6 и OpenCV.

## 1. Назначение

Программа предназначена для регистрации пользователей по видеопотоку камеры и
последующей идентификации лица на точке входа. Результат каждой попытки доступа
фиксируется в журнале.

## 2. Функциональность

| Функция | Описание |
|---|---|
| Регистрация пользователя | Захват 30 образцов лица с антидубликатной фильтрацией, сохранение образцов в `data/faces/<id>/`, автоматическое обучение модели |
| Идентификация | Распознавание в реальном времени методом LBPH; решение принимается голосованием по 7 кадрам |
| Журналирование | Фиксация успешных и неуспешных попыток в `data/logs.json`; экспорт в CSV |
| Управление пользователями | Просмотр, поиск и удаление записей вместе с образцами |
| Настройки | Порог распознавания, индекс камеры, зеркалирование изображения |
| Демо-режим | Работа без камеры с синтетическим видеопотоком (автоматически при ошибке открытия камеры) |

## 3. Технологический стек

| Компонент | Технология |
|---|---|
| Интерфейс | PyQt6, QSS (тёмная тема, стиль Fusion) |
| Компьютерное зрение | OpenCV: `CascadeClassifier` (детекция лица), `face.LBPHFaceRecognizer` (распознавание) |
| Вычисления | NumPy |
| Хранение | JSON-файлы, PNG-образцы, модель `lbph.yml` |

## 4. Требования

- Python 3.10 или выше.
- Операционные системы: Windows 10/11, Linux, macOS.
- Камера (опционально; при её отсутствии приложение работает в демо-режиме).
- Зависимости (`requirements.txt`):
  - `PyQt6 >= 6.7.0`
  - `opencv-contrib-python >= 4.9.0`
  - `numpy >= 1.26.0`
  - `Pillow >= 10.0.0`

## 5. Установка и запуск

### 5.1. Автоматическая установка (Windows)

```bat
run.bat
```

Скрипт устанавливает зависимости и запускает приложение.

### 5.2. Ручная установка

```bash
pip install -r requirements.txt
python main.py
```

При первом запуске, если файлы каскадов Хаара отсутствуют в каталоге `data/`
и в составе OpenCV, они автоматически загружаются с официального репозитория
OpenCV.

## 6. Порядок использования

1. Раздел «Главная / Скан»: нажать «Запустить камеру», затем «Сканировать вход».
2. Раздел «Регистрация»: ввести имя, нажать «Захватить 30 фото» и медленно
   поворачивать голову; обучение модели выполняется автоматически.
3. Разделы «Пользователи» и «Журнал входов»: управление записями и просмотр
   истории попыток доступа.
4. Раздел «Настройки»: порог распознавания, индекс камеры, зеркалирование,
   переобучение модели, полный сброс данных.

## 7. Конфигурация

Файл `data/settings.json` создаётся автоматически.

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `threshold` | int | `75` | Порог LBPH в диапазоне 30–120. Меньшее значение — строже проверка |
| `camera` | int | `0` | Индекс камеры в диапазоне 0–5 |
| `mirror` | bool | `true` | Зеркальное отражение видеопотока |

## 8. Хранимые данные

Все данные располагаются в каталоге `data/` и исключены из системы контроля
версий (`.gitignore`), поскольку содержат биометрические образцы.

| Файл / каталог | Содержимое |
|---|---|
| `data/faces/<id>/img_XXX.png` | Образцы лиц пользователя (200 x 200, оттенки серого) |
| `data/users.json` | Реестр пользователей: имя, дата создания, число образцов |
| `data/logs.json` | Журнал попыток доступа (последние 500 записей) |
| `data/settings.json` | Пользовательские настройки |
| `data/labels.json` | Соответствие меток модели идентификаторам пользователей |
| `data/lbph.yml` | Обученная модель LBPH |
| `data/haarcascade_*.xml` | Каскады Хаара (при автономной загрузке) |

## 9. Архитектура

Проект представляет собой единый модуль `main.py` со следующими компонентами:

| Компонент | Назначение |
|---|---|
| `FaceEngine` | Детекция лица каскадом Хаара, обучение и распознавание LBPH; резервный режим сравнения с усреднённым шаблоном при отсутствии `opencv-contrib` |
| `CameraWorker` (`QThread`) | Захват кадров камеры либо генерация синтетического видеопотока в демо-режиме |
| `VideoDisplay` (`QLabel`) | Отрисовка видеопотока: рамка лица, угловые маркеры, анимация сканирования |
| `Toast` | Всплывающие уведомления с анимацией прозрачности |
| `UnlockDialog` | Модальное окно подтверждения предоставления доступа |
| `MainWindow` (`QMainWindow`) | Навигация, страницы разделов, журналирование, настройки |

## 10. Ограничения

- Алгоритм LBPH не является средством строгой аутентификации. Качество
  распознавания зависит от освещения, ракурса и качества камеры; порог требует
  калибровки под конкретные условия эксплуатации.
- Каскад Хаара обеспечивает надёжную детекцию только при фронтальном
  положении лица и достаточном освещении.
- Резервный режим (сравнение с усреднённым шаблоном) уступает LBPH по точности
  и предназначен для базовой работоспособности без `opencv-contrib`.
- Публикация каталога `data/` (биометрические образцы, журнал) в открытом
  доступе не допускается.
