# NEON FaceID

Приложение контроля входа по лицу на PyQt6 и OpenCV: регистрация пользователя по 30 образцам с камеры, распознавание методом LBPH с голосованием по 7 кадрам, журнал попыток доступа с экспортом в CSV, управление пользователями, настройка порога (30–120), индекса камеры и зеркалирования, а также демо-режим без камеры; интерфейс выполнен в тёмной неоновой теме (стиль Fusion), все рабочие данные (образцы лиц, журнал, модель, настройки) хранятся в каталоге `data/` рядом с приложением и не включаются в репозиторий; требуется Python 3.10+ и зависимости из `requirements.txt`, запуск — `run.bat` либо `pip install -r requirements.txt` и `python main.py`, готовый исполняемый файл — в разделе Releases.

| | |
|---|---|
| **Функции** | Регистрация (30 фото), идентификация (LBPH, голосование по 7 кадрам), журнал входов + CSV, пользователи, настройки, демо-режим |
| **Технологии** | PyQt6 (QSS, Fusion), OpenCV (каскад Хаара, LBPHFaceRecognizer), NumPy |
| **Запуск** | `run.bat` (Windows) или `pip install -r requirements.txt` → `python main.py`; exe — в Releases |
| **Данные** | `data/`: `faces/`, `users.json`, `logs.json`, `settings.json`, `labels.json`, `lbph.yml` — вне системы контроля версий |
| **Архитектура** | Единый модуль `main.py`: `FaceEngine`, `CameraWorker`, `VideoDisplay`, `Toast`, `UnlockDialog`, `MainWindow` |
| **Ограничения** | LBPH не является строгой аутентификацией; точность зависит от освещения и ракурса; резервный режим без `opencv-contrib` менее точен |
